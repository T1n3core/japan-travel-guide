
# Japan Travel Guide – Natural Wonders & Scenic Routes

A visually immersive travel guide showcasing some of Japan's most beautiful natural landscapes. The website features a fullscreen image slider with parallax effects, smooth transitions, and interactive controls to create an engaging visual experience.

## Overview

The Japan Travel Guide is a photography-focused website designed to introduce visitors to Japan's natural beauty. It features a collection of scenic destinations, ranging from bamboo forests and volcanic landscapes to mountain valleys and ancient forests.

The website focuses on presenting these destinations through large background images, short descriptions, and an interactive slideshow.

## Features

- **Interactive Image Slider:** Browse through nine different Japanese natural destinations.
- **Parallax Effects:** Subtle movement effects add depth to the background images.
- **Automatic Slideshow:** Images change automatically at a configurable interval.
- **Slideshow Controls:** Pause, resume, and manually navigate between slides.
- **Adjustable Duration:** Change the slideshow interval between 1 and 9 seconds.
- **Fullscreen Mode:** Expand the website for a more immersive viewing experience.
- **UI Visibility Toggle:** Hide interface elements to focus entirely on the photography.
- **Information Overlays:** Dedicated About, Testimonials, and Contact sections.
- **Responsive Design:** Layout adapts to different screen sizes, including mobile devices.
- **Keyboard Controls:** Use the arrow keys to navigate slides, `H` to toggle the interface, and `Escape` to close overlays.

## Destinations Featured

The slideshow includes nine locations across Japan:

1. Arashiyama Bamboo Grove
2. Aso Caldera
3. Mount Fuji
4. Kamikochi Valley
5. Shirakami Sanchi Forest
6. Nachi Pagoda and Waterfall
7. Yakushima Island
8. Iya Valley
9. Tateyama Kurobe Alpine Route

- **CSS3** – Styling, responsive layouts, animations, and visual effects.
- **JavaScript** – Slideshow functionality, interactive controls, overlays, and parallax movement.

## Getting Started

No installation or additional dependencies are required.

1. Download or clone this repository.
2. Make sure the `images` folder and its contents are in the correct location.
3. Open `index.html` in your preferred web browser.
4. Explore the slideshow and its interactive features.

An internet connection is required to load the Poppins font from Google Fonts. The website itself can otherwise run locally.

## Design & Development

The website was created using a combination of original HTML development and an existing CSS/JavaScript template.

- **HTML:** Written entirely by me. This includes the page structure, navigation, slideshow content, destination descriptions, information overlays, testimonials, contact form, and image elements.
- **CSS:** Primarily based on the [Tooplate 2150 – Living Parallax](https://www.tooplate.com/view/2150-living-parallax) template, with its styling and visual effects used as the foundation for the website.
- **JavaScript:** Primarily based on the same Tooplate template, providing the slideshow functionality, parallax movement, animations, and interactive controls.

The original template was adapted to suit the Japan travel theme, including replacing the content and images and organizing the HTML around the selected destinations.
